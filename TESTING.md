# Verification — version 0.2.1

Tested locally on Windows with Python 3.12.14, PyTorch 2.5.1+cpu, NumPy, Pillow, Node.js 24.22.1, headless Microsoft Edge, aiohttp 3.14.5, and the official ComfyUI frontend package 1.57.3.

Version 0.2.1 results: **51 backend/HTTP/image/installer tests**, **5 queue-tracking JavaScript tests**, plus **25 browser checks in each renderer** (50 browser checks total), with no extension JavaScript errors. The update cell is executed with mocked Colab services to verify that it replaces the old cached ZIP while preserving a user's text and image files, including installation of the new frontend tracking module. The public-GitHub cell is tested for fresh cloning and subsequent fast-forward pulls, without accessing Colab Secrets or authentication, and installs missing bundled library files while preserving edited ones.

Regression coverage verifies that late execution results preserve edited text and newly selected files, restoring original text refreshes the gallery, and manual row choices made before execution starts survive with and without workflow metadata. Queue-tracking tests cover events arriving before the HTTP response, independent nodes, rejected submissions, and removed nodes. Backend tests verify that failed mapped batches in increment/random mode restore their initial cursor and successful batches commit all items.

Image tests use real CPU PyTorch tensors. They verify RGB float32 normalization, full resolution, grayscale/RGBA/16-bit PNG conversion, EXIF orientation, missing/corrupt previews, content-based cache invalidation, a 64 MiB cache budget, and isolation from downstream tensor mutations. Repeated increment/random executions verify matching image pixels, row, title, and description. Affix tests preserve exact spaces/newlines, leave the separate outputs unchanged, and cover pasted/connected file and title fallbacks.

Missing-image branch behavior is verified with the official ExecutionBlocker class and the unchanged upstream merge_result_data and _async_map_node_over_list functions. The upstream source is pinned at commit 4887743a2aef67e05909aeea61f6cdc93e269de3 and downloaded by tools/prepare_test_runtime.py for standalone tests; production uses ComfyUI's own installed implementation.

The backend suite checks parsing, UTF-8/BOM/CRLF input, title toggling, extra colons, missing previews, numbered-image matching, path containment, invalid inputs, file-change cache invalidation, connected input precedence, fixed/random/increment modes, queue progression, wrapping, manual resets, downstream failure recovery, HTTP routes, and installation/update preservation.

The browser suite runs against the **real production ComfyUI frontend** in both the classic LiteGraph renderer and Nodes 2.0. It tests actual graph connections to image/text consumers, delivery of the six outputs and affixes, missing-image branch skipping, and old single-output workflow migration while retaining the original text connection, File source, and empty affix defaults. Previous coverage includes gallery selection, search, save/load, metadata-free/older completion protocols, interrupted retries, manual choices during rendering, multiple queued runs, and reloads of added/replaced/deleted images and edited text. A replacement-image test preserves its filesystem timestamp and checks newly decoded browser pixels. Screenshots were inspected for layout and clipping. Synthetic test images are fixtures, not actual generated examples.

The test host uses the real node class, CPU image tensors, and HTTP routes, with a lightweight ComfyUI queue/server fixture. It does **not** load the full model executor, a diffusion model, or the user's live Colab environment. Actual GPU rendering and the user's particular Colab tunnel/notebook have not been exercised here. The GitHub repository is public at the user's request; no public node-registry submission was performed.

Reproduce the checks using the commands in README.md. Generated results are local under `test-results/`. The install notebook's Python cell is syntax-checked and executed end to end with mocked Colab Drive/upload services against a temporary ComfyUI-shaped installation. Package import/route registration and an update that preserves the existing library are also checked. Google Drive authentication and upload must run in the user's Colab session.
